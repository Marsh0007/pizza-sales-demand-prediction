This model can help the pizza related franchise to improve the stock planning , ingredient management and sales advertising.
The target variable for our this machine learning model would be pizza quantity sold, which directly represent the pizza demand. Additionally, it will help the business to predict about the inventory planning and future demand.

def time_period(hour):
    if hour < 12:

        return "Afternoon"
    elif hour < 21:
        return "Evening"
    else:
        return "Night"

8. Final Discussion¶

The machine learning analysis has been carried out for understaning the patterns of pizza sales demand using the past records.Before the model trained , the dataset has been understood properly and later operations like preprocessing has been done inorder to remove duplication , missing value or to encode the categorial variables to numerical values. The transformation of text based value to numeric was mandatory as the machine learning only understands numbers.

Two regression model were applied in this study which was Linear regression and Random forest model.Mean Squared Error and R² Score method used on both model, in which random forest model shown the lowest prediction errors and highest accuracy. That proves the random forest model are more effective in catching the complex connection within the chosen dataset which is one of the strongest point of this model.

Random Forest model showed that the pizza demands are highly affected by Total price , revenue , pizza's size and unit price of the pizza, which means both product pricing and orders characteristics plays a crucial role in customer buying patterns. There is one limitation about this model, that it can only predict on the past data from which holidays , events , promotions or seasonal treands are excluded, which might influence the demand of pizza business.

That means Machine learning can be applied to the pizza sales to support the decision making on the base of past data. It can help the businesses to understand the customer behaviour of demands for upcoming month/year , in planning of inventory and reasonable pricing according to the pizza to earn more profit.
