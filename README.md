# Pizza Sales Demand Prediction

A data-analysis and machine-learning project developed in Jupyter Notebook.

## Project workflow

- Exploratory analysis of pizza sales
- Data cleaning and preprocessing
- Feature engineering
- Categorical data encoding
- Train/test split
- Linear Regression
- Random Forest
- Model evaluation using MSE and R²
- Feature-importance analysis

## Technologies

Python, Jupyter Notebook, Pandas, Matplotlib and Scikit-learn
